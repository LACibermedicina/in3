Sobre a IN³ Política: nada nasce público. Cada camada precisa de liberação.

A IN³ (INcubator³) é a vitrine oficial da m3d.pro. Mostra apenas o que o administrador da curadoria liberar; todo o resto permanece interno e pode ser solicitado via formulário — em seguida chega por e-mail um link temporário, válido por 60 minutos, com a camada técnica liberada.

Feito com 🧊 pela equipe da m3d.pro. Código aberto, dados do GitHub real da conta LACibermedicina.

🔐 Acesso ao painel administrativo

Você pode entrar com um token enviado por e-mail (caminho dinâmico) ou com o token universal arcano — esse caminho só é aceito pelo servidor quando o administrador ativa a opção permitir token universal.

⚠️ Token universal arcano é um atalho administrativo. Para um site público em produção, desative-o no painel e use somente o envio dinâmico por e-mail (SMTP / Resend / Nodemailer).
