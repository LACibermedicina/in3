🔒 não autenticado 🌐 ver site público
🔐 Controle de acesso: esta página é separada do site público. Sem a senha correta nada é liberado. A verificação usa WebCrypto (SHA-256) no seu navegador e, opcionalmente, o login do servidor (/api/admin/login), que guarda a senha apenas como hash e devolve um token temporário de 60 minutos.

🔐 Entrar no painel

A senha é definida pelo instalador (nunca fica no código). Troque-a em tools/server.mjs (variável ADMIN_PASSWORD) antes de publicar.

➕ Criar item de portfólio

Cadastre por endereço GitHub e/ou por documentação base (playbook). Regra de ouro: todo item nasce oculto. Ele só aparece em in.m3d.pro quando você marcar “mostrar ao público”.

📚 Itens do portfólio

Marque/desmarque “mostrar ao público” e clique em Exportar curadoria. O arquivo gerado alimenta node tools/publish.mjs, que reconstrói o site respeitando exatamente as suas marcações.

🐙 Coleta GitHub (server-side)

O navegador nunca acessa a API do GitHub. A coleta roda no servidor com o token em variável de ambiente e grava apenas um cache local.
